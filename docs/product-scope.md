# Product Scope

AI SSH is a Chinese-language local desktop app for stable, reusable SSH work controlled by a local AI client through MCP.

## First-Version Layout

- Left sidebar: connection profile list.
- Main workspace: current connection session, AI-assisted action stream, and execution history.
- Right panel: session health, authorization level, and file transfer entry points.
- Bottom drawer: expandable session terminal.

## UI Language

The GUI uses Simplified Chinese. Internal code identifiers, MCP tool names, ADRs, and domain glossary terms may stay in English for implementation clarity.

## Out of First Version

- Port forwarding.
